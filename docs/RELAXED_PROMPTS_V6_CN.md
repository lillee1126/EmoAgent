# V6 宽松提示词说明

本版本以服务器备份 `emoagent_reproduction_before_batch_20260804_053102` 中的第一版提示词为基准，保留当前随机情绪、单方案、EFK 检索、断点续跑和结构化轨迹能力，同时恢复第一版的编辑尺度。

第一版只要求保留主要主体和高层布局；后续版本逐渐加入了逐实体身份、数量、轮廓、位置、尺度、透视、背景、亮度和未提及区域不变等硬限制，并要求新增内容必须次要。上一轮 20 张实验的 106 个步骤中有 28 个最终回滚；失败尝试里出现 50 次亮度门拒绝、9 次结构/改动幅度拒绝。这些约束会让 FLUX 倾向于微调，或把有效的情绪变化回滚。

V6 采用以下原则：

- 只把主要身份主体列为 protected entity，不把每个可见物体全部冻结；
- 主体保持“可识别”，场景保持“整体连贯”，不要求像素级布局一致；
- 允许明显改变姿态、表情、非身份属性、背景、天气、光照、氛围及非关键物体；
- 允许新增或替换内容成为显著情绪线索，不再强制其处于次要地位；
- 单个强情绪线索或多个互补线索都可以通过 Critic；
- 步骤验证接受自然产生的阴影、反射、邻近区域和构图变化；
- 客观图像门只拦截近乎全黑、严重损坏或完全无关的结果，不再限制正常的大幅情绪编辑。

仍保留的底线包括：不能把整幅图换成无关场景，主要主体不能被替换到无法识别，不能产生严重视觉伪影或情绪标签文字，图像必须保持可读。

此版本标识为 `single-plan-v6-first-prompt-relaxed-emotion-edit`。应使用新的 PROCESS_ROOT、RESULT_ROOT 和 METRICS_ROOT 运行，避免旧结果被断点逻辑跳过。建议先随机运行 5 张进行视觉检查，再决定是否运行新的 20 张定量实验。
